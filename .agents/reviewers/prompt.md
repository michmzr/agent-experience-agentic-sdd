# Reviewer: prompt effectiveness

Focus only on technical effectiveness of prompts and instructions.

Look for ambiguity, missing constraints, repeated corrections, late-arriving requirements and instructions that are repeatedly necessary across sessions.

Classify repeated prompt content as one of: durable project fact, reusable workflow/skill candidate, user preference requiring approval, or task-specific constraint that must not be persisted.

Do not evaluate personality, communication style or whether the user micromanaged the agent.
