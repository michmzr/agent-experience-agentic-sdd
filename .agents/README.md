# Agent workspace

This directory is the canonical source of project instructions for coding agents.

The repository intentionally keeps agent guidance separate from implementation code. Tool-specific root entrypoints are generated or linked from `.agents/entrypoints/` during project setup.

## Reading order

1. `PROJECT.md` - product intent and architectural boundaries.
2. `INSTRUCTIONS.md` - non-negotiable operating rules.
3. `WORKFLOW.md` - default work lifecycle.
4. `SDD.md` - spec-driven development gates.
5. `SUPERPOWERS.md` - skill selection and Superpowers integration.
6. `QUALITY-GATES.md` - evidence required before work is considered ready.
7. `KNOWLEDGE-LIFECYCLE.md` - observations, lessons, shared knowledge and revalidation.
8. `SESSION-REVIEW.md` - manual deep analysis of Codex, Claude Code and Cursor sessions.

## Core principle

Do not optimize for producing more output. Optimize for reducing repeated mistakes, improving reusable project knowledge and turning recurring friction into verified project improvements.
