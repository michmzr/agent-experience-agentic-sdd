# Profile: learning

Exploratory profile for repositories or workspaces where the system should learn aggressively without preventing experiments.

- Experience capture: aggressive.
- Retrieval: enabled.
- Warnings: enabled.
- Hard blocking: disabled for this user/target; BLOCK becomes WARN.
- Contradiction detection: aggressive.
- Revalidation suggestions: aggressive.
- Shared knowledge promotion: conservative.
- Successful contradictions are recorded as revalidation evidence.
