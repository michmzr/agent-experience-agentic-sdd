# Revalidate Knowledge

## Core principle

Do not silently replace old knowledge from one contradictory event.

## Workflow

1. Gather the existing entry and its evidence.
2. Gather contradictory evidence and repository changes relevant to applicability.
3. If conflict is credible, remove hard-block authority by moving the entry to disputed while revalidation is unresolved.
4. Seek the smallest reliable verification evidence.
5. Restore the entry if confirmed, or create a superseding entry if behavior changed.
6. Preserve old evidence and the supersession link for audit.

Repeated successful human overrides are a strong trigger for this skill.
