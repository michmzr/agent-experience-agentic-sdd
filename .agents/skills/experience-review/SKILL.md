# Experience Review

## Core principle

Use accumulated agent experience as telemetry for project friction.

## Perspectives

Run independent analysis from:

- system architecture;
- developer experience;
- project management.

Each perspective identifies recurring causes rather than listing individual lessons. The orchestrator then merges overlapping causes into a small improvement backlog.

## Backlog item requirements

Each item states the recurring problem, supporting lessons/findings, affected workflow, expected outcome, scope and whether SDD specification is required.

Prefer one root improvement that eliminates several symptoms over many local workarounds.
