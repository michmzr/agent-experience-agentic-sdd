# Review Lessons

## Core principle

Review knowledge for usefulness and correctness, not volume.

## Checks

For each entry, inspect scope, context, evidence, reusability, practical value, lifecycle state, duplication, contradictions and staleness.

Group related observations before creating additional lessons. Flag rules that are too broad, task-specific, unsupported or duplicated.

## Outputs

- keep as-is;
- merge/generalize;
- request more evidence;
- mark disputed;
- propose revalidation;
- reject;
- supersede;
- candidate for promotion.

Never turn a semantic reviewer opinion directly into enforced policy without the required lifecycle evidence.
