# Promote Lessons

## Core principle

Promotion expands blast radius, so promote only knowledge whose scope and evidence justify reuse.

## Repository promotion

Require project applicability, durable context, evidence and absence of unresolved contradictions. Shared repository knowledge becomes team-active only after Git merge.

## Global promotion

Always require explicit user approval. Global knowledge must be genuinely reusable across repositories rather than a project convention.

## User-instruction origin

Repository facts independently confirmed by code/tools may be eligible for automated repository promotion. Pure preferences and new skill/workflow candidates require approval. Task-specific constraints are not promoted.
