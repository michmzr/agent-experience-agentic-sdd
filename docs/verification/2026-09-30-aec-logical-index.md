The store now gives legacy and resumed technical events one transactional logical reference each. The reader uses per-session ordinals and a fixed high-water mark with pages limited to 1024 entries. Learning admission and repository quality read that stream. Opening an upgraded store backfills at most 1024 older references in one transaction. An incomplete backfill blocks the logical reader and learning admission with an explicit error; reopening resumes the next bounded transaction. Equivalent cross-path records share one logical identity. Conflicting records retain both source references in a quarantine table. Existing version 1 session output remains separate.
