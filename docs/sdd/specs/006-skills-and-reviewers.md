# Spec 006: skills and reviewer profiles

## Status

Approved baseline.

## Goal

Provide reusable agent workflows for knowledge review, promotion, revalidation, session review and project improvement analysis.

## Required behavior

- Skills are thin semantic workflows over deterministic project tooling when implementation exists.
- Built-in reviewers cover prompt effectiveness, tools/workflow, failures/learning, temporary artifacts, code changes, architecture, developer experience and project management.
- Custom reviewers are supported.
- Review profiles can compose built-in and custom perspectives.
- Project skills do not replace Superpowers process skills.
- Skill creation and updates follow skill-authoring validation practices.

## Acceptance

An agent can discover the correct project workflow from trigger-focused skill descriptions and produce outputs with clearly defined boundaries.
