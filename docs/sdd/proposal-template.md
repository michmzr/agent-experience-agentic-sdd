# Improvement proposal template

## Origin

Session, review, finding or lesson identifiers.

## Problem

Concrete recurring friction or risk.

## Evidence

Observed occurrences and repository verification.

## Proposed outcome

Describe the desired improvement, not implementation detail.

## Category

Knowledge | documentation | skill | tooling | developer experience | architecture | process

## Expected effect

What repeated cost, error or ambiguity should be reduced.

## Scope

Affected repository/workspace and workflows.

## Requires full specification?

Yes when executable behavior, architecture, tooling, skills or project workflow changes.

## Decision

Proposed | Accepted for spec | Rejected | Deferred
