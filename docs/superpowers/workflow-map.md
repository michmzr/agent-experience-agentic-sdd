# Superpowers workflow map

| Situation | Required/default process |
| --- | --- |
| New architecture or behavior | brainstorming -> spec approval |
| Approved multi-step spec | writing-plans |
| Feature or bugfix implementation | test-driven-development |
| Unexpected failure | systematic-debugging |
| 2+ independent investigations | dispatching-parallel-agents |
| Isolated implementation | using-git-worktrees |
| Execute detailed plan with fresh agents | subagent-driven-development |
| Execute plan inline | executing-plans |
| Create/change project skill | writing-skills |
| Before completion claim | verification-before-completion |

Project-specific skills are selected after the relevant process skill.
